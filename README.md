# Overview

SmartFormAI is an intelligent document analysis system capable of:

- Detecting fields inside PDF forms
- Understanding document layouts
- Performing OCR using PaddleOCR or EasyOCR
- Extracting personal information
- Mapping extracted data to form fields
- Automatically filling PDF forms
- Exporting completed documents
